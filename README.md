# Glance

A Mac companion that already knows what you've been doing across every app.
Point at anything on screen, speak, and it explains it or guides you through it, privately.

Built at Dublin HacX. Full plan: [docs/PLAN.md](docs/PLAN.md). Current state and next steps: [docs/HANDOFF.md](docs/HANDOFF.md).

## Run
```bash
./scripts/selftest.sh    # build + assert-based self-tests
./scripts/build-app.sh   # build build/Glance.app, sign it, launch it
```
Menu-bar app (eye icon). ⌥Space toggles the panel.
